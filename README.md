# ប្រព័ន្ធគ្រប់គ្រងសហគ្រាសផលិតទឹកបរិសុទ្ធខ្នាតតូច
## Pure Water Factory POS, Debt & Financial Management System (SrpErp)

ប្រព័ន្ធគ្រប់គ្រងការលក់ POS តាមដានសំបកធុង ២០លីត្រ ជំពាក់ បំណុល និងរបាយការណ៍ហិរញ្ញវត្ថុចំណេញ/ខាតពិតប្រាកដ ត្រូវបានរចនាឡើងយ៉ាងសាមញ្ញ ស្រាល រហ័ស និងមានប្រសិទ្ធភាពខ្ពស់ ស្របតាមប្រតិបត្តិការជាក់ស្តែងរបស់សហគ្រាសផលិតទឹកបរិសុទ្ធនៅកម្ពុជា។

---

### ១. ព្រំដែនអាជីវកម្មជាក់លាក់ (Strict Business Boundaries)

1. **គ្រប់គ្រងតែផលិតផលទឹកសម្រេច (Finished Goods Only):**
   - ទឹកធុង ២០លីត្រ (ប្តូរសំបក / ទិញទាំងសំបក)
   - ទឹកដបកញ្ចប់ ៣៥០មល (១យួរ=២៤ដប)
   - ទឹកដបកញ្ចប់ ៥០០មល (១យួរ=២៤ដប)
   - ទឹកដបកញ្ចប់ ១៥០០មល (១យួរ=១២ដប)
   - **មិនបញ្ចូល** វត្ថុធាតុដើម (គម្រប, គ្រាប់ផ្លុំ, ស្លាកសញ្ញា, ស្រោមបង្រួម, ស្នូលតម្រងចម្រោះ) ទៅក្នុងស្តុកទេ។
2. **គ្មានប្រព័ន្ធកាត់ស្តុក ឬបញ្ជាទិញទំនិញ (No Inventory/PO Workflows):**
   - មិនមាន Purchase Orders, Reorder Points ឬ Bin Tracking ស្មុគស្មាញឡើយ។
3. **ទំនិញខូចខាតបែកបាក់កាត់កងជាការខាតផ្ទាល់ (Broken Products as Direct Loss):**
   - ធុងធ្លាយ ទឹកដបបែកពេលដឹកជញ្ជូន ត្រូវបានគណនា៖ `Broken Loss = ចំនួនខូចខាត × ថ្លៃដើមផលិត`។
   - ទឹកប្រាក់នេះត្រូវបានកាត់កងដោយផ្ទាល់ចេញពីប្រាក់ចំណេញប្រតិបត្តិការ។
4. **តាមដានសមតុល្យសំបកធុង ២០លីត្រ ជំពាក់ (Empty Bottle Ledger):**
   - តាមដានចំនួនសំបកធុងដែលអតិថិជននីមួយៗកំពុងកាន់កាប់ជាក់ស្តែង (សំបកធុងជំពាក់) រាល់ពេលដឹកជញ្ជូន និងពេលយកត្រឡប់មកវិញ។
5. **ម៉ូដែលហិរញ្ញវត្ថុពិតប្រាកដ (Exact Financial Model):**
   - **Gross Sales** = ផលបូកតម្លៃលក់លើវិក្កយបត្រទាំងអស់
   - **Operational Expenses** = ផលបូកចំណាយប្រចាំថ្ងៃ (ភ្លើង EDC, ប្រេងឡាន, ឈ្នួល, ជួសជុល)
   - **Broken Loss** = ផលបូកទំនិញខូចខាតបែកបាក់
   - **Net Profit** = Gross Sales - (Operational Expenses + Broken Loss)
   - **Customer Receivables** = សរុបបំណុលដែលអតិថិជនមិនទាន់ទូទាត់

### ២. ម៉ូឌុលទាំង ១១ នៃប្រព័ន្ធ (11 Active Modules)

| # | ម៉ូឌុល | មុខងារចម្បង |
|---|---|---|
| 1 | **Dashboard** | មើលចំណូលថ្ងៃនេះ, បំណុលជំពាក់សរុប, សំបកធុង ២០L នៅអតិថិជន, ចំណេញសុទ្ធប្រចាំខែ |
| 2 | **POS (លក់រហ័ស)** | ចុចលើអេក្រង់ Touchscreen, ជ្រើសរើសអតិថិជន, ចុះកិច្ចសន្យាប្តូរសំបកធុង, ព្រីនវិក្កយបត្រកម្តៅ 80mm |
| 3 | **Order History** | ស្វែងរកវិក្កយបត្រចាស់ៗ, ព្រីនឡើងវិញ (Reprint), លុបចោលវិក្កយបត្រមានបញ្ហា |
| 4 | **Products** | បញ្ជីទឹកធុង និងទឹកដបសម្រេច, កំណត់ថ្លៃដើម, តម្លៃលក់, ភាគរយចំណេញដុល |
| 5 | **Broken Loss** | កត់ត្រាធុងទឹកបែកធ្លាយ, គណនាទឹកប្រាក់ខាតបង់ស្វ័យប្រវត្តិ, មូលហេតុខូចខាត |
| 6 | **Customers** | បញ្ជីអតិថិជន, អាសយដ្ឋានដឹក, សមតុល្យសំបកធុង ២០L, សមតុល្យបំណុល, កែសម្រួលសំបក |
| 7 | **Debt & Receivables** | បញ្ជីអ្នកជំពាក់, ទទួលប្រាក់សងបង្គ្រប់ជាដុល្លារ ($) ឬរៀល (៛), ប្រវត្តិទូទាត់ |
| 8 | **Expenses** | កត់ត្រាចំណាយប្រតិបត្តិការ (ថ្លៃភ្លើង EDC, ប្រេងឥន្ធនៈ, ប្រាក់ឈ្នួល, ថែទាំម៉ាស៊ីន) |
| 9 | **Suppliers** | សៀវភៅលេខទូរស័ព្ទទាក់ទងបន្ទាន់ (រោងចក្រផ្លុំធុង, ជាងម៉ាស៊ីន RO, រោងពុម្ពតែម) |
| 10 | **Reports** | របាយការណ៍ចំណេញ/ខាត P&L, របាយការណ៍ផ្ទៀងផ្ទាត់សំបកធុង ២០L, របាយការណ៍បំណុល |
| 11 | **Settings & Users** | កែប្រែអត្រាប្តូរប្រាក់ ($ / ៛), ព័ត៌មានរោងចក្រ, ប្តូរសិទ្ធិប្រើប្រាស់ (Admin/Cashier/Driver) |

### ៣. រចនាសម្ព័ន្ធបច្ចេកវិទ្យា (Tech Stack)

- **Frontend:** Next.js 14 (App Router) + React 18 + TypeScript
- **Styling:** Tailwind CSS + Lucide Icons + Google Fonts (Kantumruy Pro & Inter)
- **Database Engine:** PostgreSQL / Supabase Migration Ready (`supabase/migrations/`)
- **State & Offline Cache:** LocalStorage reactive store with realistic factory seed data
- **Thermal Printing:** 80mm / 58mm ESC/POS layout with `@media print` styling

---

### ៤. របៀបដំណើរការ (Getting Started)

ដំណើរការម៉ាស៊ីនមេក្នុងកុំព្យូទ័រមូលដ្ឋាន៖

```bash
npm run dev
```

បើកកម្មវិធីរុករក (Browser) ទៅកាន់៖ **http://localhost:3000**
